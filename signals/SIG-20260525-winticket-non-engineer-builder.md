# 非工程師開始成為可治理的 AI Builder

## 事件摘要
WINTICKET 為 24 名商務與設計職設計 6 回 Claude Code 訓練，內容從 Terminal、Git、GitHub、permissions 到供應鏈安全；一個月內非工程師提交超過 13 個 PR，並開始自行製作 Skills / plugins 與自動化腳本。

## 為何重要
這不是「非工程師做 demo」，而是把 software production capability 擴展到原本不寫程式的角色，同時加上安全邊界與工程 review。這直接改變小團隊與獨立 Builder 的能力邊界。

## 原始證據
- 24 名非工程師參加，包含 business / designer。
- 一個月 GitHub PR 超過 13 件。
- 有成員自行製作 Claude Code Skills / plugins 並在 GitHub 分享。
- 行銷成員建立 marketing report 自動化 script。
- Production 之外仍要求工程師 review，並加入 permissions、套件供應鏈與 security 訓練。

## 對小型團隊／獨立 Builder 的價值
核心不是學更多程式，而是建立「可以安全委派給 Agent 的工作面」。產品、內容、資料分析、網站維運、報表與內部工具都可能從需求者直接變成 Builder。
