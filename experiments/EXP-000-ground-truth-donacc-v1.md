# EXP-000 Ground Truth｜DON ACC. Replay｜Human-only

> 這份檔案是 EXP-000 的事前答案基準。Replay Agent 不得讀取。
> 只有「在實驗開始前已經明確確定」的內容可以列入評分；帶推論或尚未定案的內容不得拿來扣 Replay 分數。

## 1. 品牌核心定位｜已確定

- 品牌：懂飾 DON ACC.
- 定位：「新中式 × 日常祝福感」飾品品牌。
- 核心概念：「把祝福戴進日常，把心意留在身邊。」
- 主要商品包含水晶／天然石、硃砂系、編織手繩、平安扣、手鍊、項鍊、吊墜與送禮型飾品。
- 品牌不是販售誇大玄學效果，而是提供可融入日常穿搭、帶有溫潤祝福寓意、適合自用與送禮的飾品。
- 品牌視覺與內容應維持：溫潤、乾淨、自然、有質感、日常可佩戴。

## 2. 網站主要商業目標｜已確定

網站不是單純品牌形象展示，必須同時支援：

1. 提升商品購買轉換。
2. 降低消費者選購困難。
3. 強化「送禮」購買理由與選購路徑。
4. 建立材質、商品故事、品牌理念、售後與購買信任。
5. 承接 Meta 廣告與其他導流，不讓流量落到無法理解或轉換的頁面。
6. 支援 Google 搜尋與長期內容／SEO 資產累積。
7. 讓懂飾維持穩定現金流，而不是為了網站技術本身而增加維護負擔。

## 3. 主要客群｜已確定到需求層，不鎖人口輪廓

主要不是依年齡／職業 Persona 定義，而是依購買情境：

### 自用
- 想找能日常佩戴、有設計感但不過度華麗的祝福型飾品。
- 重視美感、搭配性、材質、佩戴感與寓意。
- 不希望商品帶有強烈宗教感、恐嚇式玄學或命運焦慮。

### 送禮
- 想送出「有心意、有祝福感、又實際可佩戴」的禮物。
- 需要快速理解商品寓意、適合送誰、送禮情境與包裝體驗。
- 害怕選錯、尺寸不合、寓意不清楚或禮物看起來廉價。

> 不把「某特定年齡、職業、收入」列為 Ground Truth，除非後續已有明確數據證明。

## 4. 核心購買／行動理由｜已確定

消費者購買理由應主要來自以下組合，而非功效承諾：

- 商品設計與日常佩戴感。
- 天然石／硃砂／編織等材質與細節。
- 溫和且容易理解的祝福寓意。
- 自用時的陪伴感與日常儀式感。
- 送禮時「有心意但不過度傳統」的理由。
- 商品故事與系列概念。
- 包裝與送禮完整度。
- 尺寸、材質、保養、退換貨等資訊帶來的信任。

## 5. 必要網站能力與主要轉換路徑｜已確定原則

### 必要能力
- 清楚理解品牌與商品差異。
- 可依商品／系列／需求進入選購。
- 商品頁可完成購買決策：外觀、材質、尺寸／佩戴、寓意、送禮、保養與必要購買資訊。
- 完整購物車、結帳、付款、物流及訂單流程。
- 能承接廣告流量。
- 能累積 SEO 與品牌內容。
- 支援送禮需求與包裝溝通。

### 已確定的核心轉換路徑原則

1. 品牌／自然進站 → 理解品牌 → 找到適合商品 → 商品頁 → 購物車／結帳。
2. 商品／廣告導流 → 對應商品或系列落地 → 商品理解與信任 → 購物車／結帳。
3. 送禮需求 → 找到適合送禮的商品／情境 → 商品頁 → 購物車／結帳。
4. 搜尋／內容進站 → 解決疑問／建立信任 → 相關商品或系列 → 商品頁 → 結帳。

> Exact IA／頁面命名若在 Replay 前沒有另外凍結，不作為本次 Ground Truth 的硬性答案；本實驗主要評估 Agent 能否從上述商業要求推導合理 IA。

## 6. 已確定不採用的方向｜已確定

- 不再沿用 WordPress + WooCommerce 作為新站核心架構。
- 不以「AI 很新」為理由加入沒有實際需求的 AI 功能。
- 不做廉價叫賣式網站。
- 不以大量折扣、倒數、壓迫式促銷作為品牌主要轉換手段。
- 不用恐嚇式玄學、命運焦慮或「不買會怎樣」推動成交。
- 不用財運、健康、改運等高風險／不可驗證功效保證。
- 不做過度宗教化、過度傳統、與日常佩戴距離太遠的呈現。
- 不為少數特殊需求增加大量系統複雜度。
- 不因「一般電商都有」就預設會員、複雜推薦、AI 導購等功能必須存在。

## 7. 品牌／文案／UX 禁區｜已確定

### 品牌與文案
- 避免廉價促銷感。
- 避免誇大、保證、製造恐懼。
- 避免把天然石／硃砂寫成具有確定財運、健康或命運效果。
- 避免大量空泛形容詞而缺乏材質、故事、使用情境與細節。
- 新中式應是現代、乾淨、可日常佩戴，而非古風堆砌。

### UX
- 不應讓使用者因分類、寓意或商品差異太多而更難選。
- 商品頁不能只漂亮而缺乏尺寸、材質、佩戴、送禮與購買資訊。
- 廣告流量不應被迫先閱讀大量品牌故事才可找到商品。
- 網站架構與頁面必須有清楚的使用者任務或商業理由。

## 8. 技術／平台邊界｜已確定

- 新站方向為 AI-native 重構，不延續 WP + WooCommerce 的肥大架構。
- 電商核心能力已確認可由 donix commerce / 既定 AI-native 電商系統承接，包含既有 SKU、購物車、結帳、付款、物流等核心需求。
- 不因本次 Replay 重新評估或開發完整電商 backend。
- 本次 EXP-000 不進入 frontend coding、deployment、database、dashboard、crawler、multi-agent 或 multi-model orchestration。
- 技術選擇應服務維護成本、轉換、SEO、資料掌控與長期可擴充性，不以技術新穎度作為目標。

## 9. 已知最終判斷｜可用於事後比對

Replay 的 Consult / Spec 至少應理解以下方向，否則視為重大偏差：

1. DON ACC. 的核心不是玄學功效，而是「新中式 × 日常祝福感 × 日常佩戴／送禮」。
2. 網站必須同時服務購買轉換、送禮、信任建立與長期搜尋資產，而不是純形象官網。
3. 商業優先級高於炫技；不應無理由增加 AI、會員、複雜推薦等功能。
4. 使用者必須容易理解「這是什麼、適不適合我／送人、為什麼值得買、怎麼選、怎麼安心下單」。
5. 商品頁是核心成交節點，必須承擔商品理解、信任與購買決策，不只是圖片展示。
6. 品牌體驗必須維持質感、溫潤、自然與現代感，避免廉價促銷與焦慮型玄學。
7. 新站不應回到 WP + WooCommerce 架構。
