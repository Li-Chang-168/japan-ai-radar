# Rakuten 把 Claude Code 當成可並行工作的開發資源

## 事件摘要
Rakuten 公開 Claude Code 的企業實務：在複雜開源 refactoring 任務中連續自主執行 7 小時；新功能 time-to-market 從 24 天降至 5 天；工程師並行啟動多個 Claude Code session，把自身角色轉為同時管理多個工作流。

## 為何重要
真正的生產力提升不是單一 task 加速，而是把「可同時推進的工作數」放大。這是 AI coding 從 assistant 模式跨向 parallel agent capacity 的早期強證據。

## 原始證據
- 7 小時 sustained autonomous coding。
- 新 feature time-to-market 由 24 個工作天縮短為 5 天，約 79%。
- 複雜 code modification 報告 99.9% numerical accuracy。
- 官方案例描述工程師可同時運行多個 session，自己聚焦一項、其餘委派給 Claude Code。
